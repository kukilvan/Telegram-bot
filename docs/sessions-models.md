# Какую модель и effort выбирать для сессии

Шпаргалка для владельца. Смотреть при создании каждой новой сессии.

**Модель** — какой Claude работает. **Effort** («усердие») — сколько модель думает перед ответом: `low` → `medium` → `high` → `xhigh` → `max`. Чем выше, тем лучше на трудных задачах и тем больше расход.

Модели по возрастанию силы и цены: **Haiku 5.5** → **Sonnet 5.5** (примерно вдвое дешевле Opus) → **Opus 5.5** → **Fable 5.1** (примерно в 2,5 раза дороже Opus).

## Главная таблица

| Сессия | Модель | Effort | Почему |
|---|---|---|---|
| **Описание** части работы | Opus 5.5 | high | Здесь принимаются решения; ошибка в описании тянется через спеку и все тикеты |
| **Спека** | Opus 5.5 | high | То же; для самых важных частей (каркас веб-приложения, игры и цены) — `xhigh` |
| **Нарезка на тикеты** | Sonnet 5.5 | high | Работа по готовой спеке, решать почти нечего |
| **Тикет «простой» или «средний»** | Sonnet 5.5 | high | Код по ясному тикету: экран, кнопка, текст, правка |
| **Тикет «сложный»** | Opus 5.5 | high | База и миграции, опрос и события, аниме, одновременная работа бота и веба |
| **Код-ревью** части | Opus 5.5 | xhigh | Ищет ошибки, которые пропустили тикеты; экономить здесь дороже |
| **Правка по «Есть замечания»** | та же, что была | та же | Продолжайте в той же сессии, модель не меняйте |
| **Вопрос, обсуждение, «как сделать»** | Sonnet 5.5 | medium | Без кода |

Сложность пишет в каждом тикете сессия нарезки (строка «Сложность»). Рекомендованные модель и effort для следующей сессии стоят в строке «Следующий шаг» в `PROJECT_CONTEXT.md` — их можно просто взять оттуда.

## Когда брать другое

- **Fable 5.1** — только если Opus дважды не справился с одной задачей или перед публикацией шаблона на GitHub (кусок 8) для итогового ревью. Не по умолчанию.
- **`max`** — не использовать: прибавка к качеству мала, расход большой.
- **Haiku 5.5** — для кода этого проекта не брать: дёшево, но ошибки обойдутся дороже.
- **Sonnet застрял** (третья попытка того же, ходит по кругу) — не спорьте в той же сессии: откройте новую на Opus 5.5 и напишите «дальше, прошлая сессия не справилась с …».

## Как тратить меньше

1. **Одна сессия — один шаг** (так устроен порядок работы). Длинная сессия с несколькими задачами дороже: каждый новый ответ перечитывает всю переписку.
2. **Модель и effort выбирайте в начале** и не меняйте посреди сессии: смена сбрасывает сохранённый контекст, и он считается заново.
3. **Новую сессию начинайте словом «дальше»** — не пересказывайте историю, всё есть в документах.
4. **Замечания пишите одним сообщением**, списком, а не по одному.
