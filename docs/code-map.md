# Карта кода

Что лежит в каждом файле `app/`. Общая схема и технологии — `PROJECT_CONTEXT.md`, раздел 5; куда класть новый код — `docs/coding-standards.md`, правило 7. Обновлять вместе с кодом.

| `app/runtime.py` | Один процесс: `Runtime` запускает веб, планировщик (и задачу-метку «планировщик жив» раз в 30 с), бота и сторож, ловит `SIGTERM` / `SIGINT` (на Windows — отмену главной задачи по `Ctrl+C`), останавливает по порядку (сторож → веб и бот → ожидание задач до 15 с → сессия Telegram → «остановлено»), при смерти части — общая остановка и код 1; часть «бот» повторяет подключение (30 с, вдвое, до 5 мин; к 30 с пауза возвращается, когда часть сообщила о старте приёма — `receive(started)`, KI-14); `Health` — что отвечает `/health`; `Watchdog` — поток, выход `os._exit(1)`, если цикл не ставит метку 60 с на двух проверках подряд.
