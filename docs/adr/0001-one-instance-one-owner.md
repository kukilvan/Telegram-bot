# Один экземпляр бота — один владелец

Бот рассчитан на одного человека: у каждого экземпляра свой список, свои ключи API и свой часовой пояс. Опрос источников идёт по тайтлам владельца без рассылки нескольким подписчикам. Нужен другой человек — он разворачивает собственный экземпляр по инструкции из репозитория. Так проще модель данных и опрос, а код можно выложить на GitHub как шаблон «сделай себе такого же».

## Consequences

- Таблица пользователей и белый список остаются только как защита от чужих сообщений.
- Всё, что сейчас захардкожено под владельца (часовой пояс, регион Steam и PSN, личные файлы в корне репозитория), выносится в настройки или удаляется.
