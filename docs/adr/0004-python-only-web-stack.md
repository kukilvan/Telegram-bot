# Веб-приложение пишем на Python (FastAPI и HTMX), без отдельного фронтенда

Приложение и бот живут в одном Python-проекте с общей базой и одним Docker-образом: FastAPI отдаёт страницы-шаблоны, HTMX даёт живой поиск и обновление без перезагрузки, PWA-манифест позволяет поставить его на телефон. Отдельное React-приложение дало бы больше интерактивности, но потребовало бы второго образа и сборки на Node, а для личного трекера и шаблона на GitHub важнее простая установка и поддержка.

## Consequences

- Если интерфейс упрётся в возможности HTMX, фронтенд заменяется на React поверх тех же данных и API, не трогая ядро.
