# Веб-приложение — основной интерфейс, Telegram-бот — канал уведомлений

Список, карточки, архив с сортировкой по оценке и жанру, поиск и оценки живут в веб-приложении (PWA). Бот присылает события и принимает быстрые действия («посмотрел», «следить»), а кнопка в сообщении открывает нужную карточку. В чате такой архив и поиск неудобны, а push-уведомления PWA на iPhone ограничены, поэтому Telegram остаётся единственным каналом доставки.

Приложение и бот поставляются как Docker-контейнеры. Разрабатываются и проверяются на ПК, затем в том же виде переезжают на домашний NAS (предварительно UGREEN DXP2800).

## Consequences

- Нужен постоянно работающий сервер и доступ к приложению с телефона по HTTPS.
- Inline-поиск в боте больше не нужен: поиск с подсказками по мере набора делает веб-приложение.
- Шаблон для GitHub сложнее в установке, чем «один бот»: это принимается ради удобства.
