# Веб открывается для домашней сети по желанию владельца

Порт веб-приложения по умолчанию опубликован только на `127.0.0.1` (ADR 0006): открыть его можно лишь с того же ПК. Владельцу нужно смотреть приложение с телефона в домашней сети Wi-Fi, поэтому адрес публикации стал настройкой `WEB_HOST` в `.env`: `127.0.0.1` (по умолчанию) — только этот ПК; `0.0.0.0` — ещё и устройства домашней сети по адресу ПК, например `http://192.168.1.124:8080`. Включает владелец сам, одной строкой в `.env`.

Рассмотрено и отвергнуто: открыть для сети всегда (шаблон для GitHub не должен быть открыт «из коробки»); сразу делать доступ вне дома через Tailscale или Cloudflare Tunnel — это кусок 7, когда появится NAS (ADR 0006).

## Consequences

- Защита та же: вход по паролю, блокировка после неверных попыток, проверка `Origin` (по заголовку `Host`, поэтому работает и при заходе по адресу ПК). Связь по `http` не шифруется: пароль виден тому, кто слушает домашнюю сеть. Подходит для дома без чужих устройств; не открывать порт в роутере наружу.
- Брандмауэр Windows может не пускать входящие подключения на порт: правило добавляет владелец сам.
- Адрес ПК в сети может смениться после перезагрузки роутера; надёжный вариант — закрепить адрес за ПК в настройках роутера.
- Установка на телефон как приложение (PWA) требует `https` и по-прежнему проверяется позже (ADR 0006).
