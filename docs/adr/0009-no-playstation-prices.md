# Цен PlayStation нет: ключ PlatPrices для личных нужд не выдают

ADR 0003 выбрал PlatPrices единственным источником цен, скидок и бандлов PlayStation. 2026-10-30 PlatPrices отказал владельцу в ключе: для личного использования ключи не выдают. Других документированных источников цен PlayStation Store нет. Поэтому цен, скидок и бандлов PlayStation в трекере нет. Это решение отменяет ADR 0003.

PS5 остаётся платформой владельца:
- события «игра вышла на PS5» и даты выхода приходят из IGDB;
- цены и скидки есть только у Steam;
- в карточке игры для PS5 есть ссылка в PlayStation Store, чтобы посмотреть цену самому. Будет это страница игры или поиск по названию, решит спека куска 6;
- о скидках на игры из списка желаемого в PS Store сообщает сама PlayStation.

Рассмотрено и отвергнуто:
- Читать цены со страниц PS Store или неофициальным запросом. Такой запрос ломается без предупреждения — так было с прежним клиентом, и ADR 0003 отверг его даже как запасной.
- Сайты, которые собирают цены PlayStation (PSPrices, PSDeals). Открытого API у них нет, цены пришлось бы вытаскивать из страниц. Это так же хрупко и упирается в их условия.

## Consequences

- Кусок 6 становится проще: нет ключа, квоты в 1000 запросов в месяц и надписи «Powered by PlatPrices».
- У игр PlayStation нет событий «скидка» и «бандл». Если игра есть и в Steam, скидка на неё приходит по Steam.
- Тому, кто поднимает свой экземпляр по шаблону с GitHub, ключ для PlayStation не нужен.
- Если появится документированный источник цен PlayStation с ключом для личных нужд, его добавляют новым ADR.
