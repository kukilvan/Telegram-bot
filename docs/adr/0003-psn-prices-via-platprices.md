# Цены PlayStation берём из PlatPrices

У PlayStation Store нет официального API; прежний неофициальный запрос с хэшем ломался без предупреждения. Для цен, скидок и бандлов PlayStation используем документированный API PlatPrices v2: бесплатный ключ выдаётся вручную по e-mail, пакетный запрос раз в сутки по играм со статусом «Хочу» укладывается в бесплатную квоту. Неофициальный запрос не используем даже как запасной: два хрупких источника хуже одного.

## Consequences

- Ключ PlatPrices необязателен: без него цены PlayStation выключены, остальное работает.
- Каждый, кто поднимает свой экземпляр, получает собственный ключ и показывает надпись «Powered by PlatPrices»; коммерческое использование запрещено условиями бесплатного тарифа.
- Поиск с подсказками при наборе не должен обращаться к PlatPrices (квота 1000 запросов в месяц): подсказки идут из IGDB, а PlatPrices вызывается при добавлении игры и в суточном опросе.
- Доступность региона Израиль нужно проверить запросом `GET /regions` после получения ключа.
