## What to do

- **The client `app/providers/zog.py` (5.6).** `GET https://www.zoneofgames.ru/games/<page>/`, `User-Agent: release-tracker (personal game tracker; one page per game a week)` with no owner details; 10 s; redirects not followed (any answer but 200 is a failure); the body decoded from `windows-1251`.
- **`sources/zog_pages` (pure).** Reading a page: `<title>` «Ошибка» — no such page (ZoG answers 200 for it); «<name> | Игровой архив на Zone of Games» — a game page, `name` before « | », entities opened; any other title — unreadable. The year: the first `/games/year/<YYYY>.html` after «В официальной продаже с»; missing — none. The entries: after «Переводы:» up to the next `</table>`, the links `/games/<page>/files/<n>.html`; no «Переводы:» — Support(no, no); «Переводы:» with no such link — unreadable. An entry counts when its text starts with «Русификатор (»: the words in the first brackets — «текст» gives text, «звук» voice («текст и звук» both; «текстуры», «видео» and the like nothing); «для <X>-версии» with X other than «ПК» → not counted; «для ПК-версии», no platform, «для Phantom Liberty» → counted; «Українізатор», «Беларусізатар» not counted. The pages and what they must give: `baldurs_gate_3` text + voice, `hades_2` voice, `lorelei_and_the_laser_eyes` text (its Switch entry not counted), `split_fiction` text + voice, `lies_of_p` voice, `disco_elysium` voice, `cyberpunk_2077` voice, `prey` text + voice (year 2006), `stray` none, `astro_bot` none (no «Переводы:»), `the_witcher_3_wild_hunt` «Ошибка».
- **Addresses and matching (5.6).** The address of a name: accents dropped (NFKD), lower case, «'», «’», «.» removed, every other run of non-`[a-z0-9]` → «_», trimmed. Finding (no page stored, or the stored one answered «Ошибка»): from the original name, in order, each once, at most 4 requests — (1) the name; (2) its numbers switched (a Roman word II–X to Arabic, or, when none, an Arabic word 2–10 to Roman); (3) the name before the first «:» or « - » / « – »; (4) the switch of (3). «Baldur's Gate III» → `baldurs_gate_iii` (none) → `baldurs_gate_3`; «Hades II» → `hades_ii` → `hades_2`. A found page is taken only when the match key (accents dropped, lower case, «ё»→«е», Roman II–X → Arabic, only letters and digits, spaces squeezed) of ZoG's name equals the key of the original name, the Russian name, or either before its «:» — and the page's year, when both have one, is not earlier than the year before the game's (`Title.year`): `prey` (2006) is refused for Prey (2017); «S.T.A.L.K.E.R. 2: Heart of Chornobyl*» matches. Nothing taken → «not found», checked again in 7 days. `page_of(link)` (pure; used by ticket 06) is written here with the address helpers.
- **`pollers/game_zog` (5.6).** For games for Russian (`for_russian`), snapshot `zog`: at most 2 games a pass (`ZOG_PER_PASS`), never-checked first, then the earliest; 1 s between requests; after a check 7 days; after a failure 6 hours, a log line, **no message to the owner**; a rejected page is never asked (next check set 7 days on). The state: `{}`; `{"page", "by": "found"|"owner", "text", "voice"}`; `{"page", "by", "unreadable": true, …previous text/voice kept}`; `{"page": null, "by": "none"}`; `{"page": null, "by": "rejected"}`. An unreadable layout keeps the last Support of the same page and logs once a day (`DailyLog`). Reference point: the first read of a page, the first check after «Вернуть в список». Events: each of text and voice that is yes now and was not **and that the official lacks now** (the official read in the same session from `russian_official`), queued in one write session with `still_checked` and `statuses`, then the state stored. The reconciliation makes an empty `zog` snapshot for games for Russian, never drops one.
- **The fan segment and hints (5.2, 5.3).** `russian.line` gets the fan part: «текст и озвучка — народные», «текст — народный», «озвучка — народная», filling only what the official lacks; the «(ПК)» rule for it. Hints: «… · ZoG — проверено 18 ноября» in the sources hint; the page states — not found «Страница на ZoG не найдена — вставьте ссылку, если перевод есть», rejected «Страница на ZoG не указана — вставьте ссылку, если перевод есть», unreadable «Страницу на ZoG не удалось прочитать — народный перевод пока неизвестен»; the link «Страница перевода» (the ZoG page) in the web block when a fan segment is shown. The form comes in ticket 06 (the hints already say «вставьте ссылку»; ticket 06 adds the field). Bot card: the link button «🌐 Страница перевода» under the card, before «🗑 Удалить» (`card_actions`), when a fan segment is shown.
- **Messages (5.8, fan).** `game_russian_fan` in `russian_events` (the same `TYPES` list): «🎮 Для «Lorelei and the Laser Eyes» вышел народный русский перевод текста», «🎮 Для «Baldur’s Gate 3» вышла народная русская озвучка», «🎮 Для «Split Fiction» вышли народный русский перевод текста и озвучка», « (ПК)» by the rule of 5.2; the key `moved_key("game:<id>:russian:fan:<page>:<parts>", previous_look)`; the payload `{"text", "name", "parts", "zog_page", "pc"}`; buttons «📄 Карточка» and «🌐 Страница перевода»; the sample «Игра: народный перевод» («Baldur’s Gate 3», voice, `baldurs_gate_3`). No folding; a line each in a summary and in «Недавно».
- **ADR 0016** «Fan translations are read from ZoG game pages», in the format of `docs/formats.md`: no API, Google search only; the page address by the name, the name and year match, the owner's link; the answer to ADR 0009's reason (a page breaks without warning): here a broken layout shows «unreadable» and keeps the last value, a log line a day, no message invented, no money at stake; rejected — GamesVoice and others (not one catalog), ZoG's own search (JavaScript), asking the owner for every game.
- **Docs:** docstrings, `tools\code_map.py`, `docs/tests-map.md`, rule 7 table (three new modules); `CONTEXT.md` — «Народный перевод», the ZoG half of «Проверка русского языка»; `PROJECT_CONTEXT.md`, «External services»: the new row ZoG.

## Owner check

The session starts the bot and writes the launch result in one line. Then:
1. Add Baldur's Gate 3 to «Хочу» (the web search, as usual). After two or three minutes reload the card: the line reads «Русский: текст — официально; озвучка — народная» and under the block there is a link «Страница перевода» that opens the game's page on zoneofgames.ru.
2. The bot card of the same game shows the same line and the button «🌐 Страница перевода».
3. In «Настройки» press «Тестовое событие» → «Игра: народный перевод»: «🎮 Для «Baldur’s Gate 3» вышла народная русская озвучка» with «📄 Карточка» and «🌐 Страница перевода».
4. A game ZoG does not have (for example Stray: only «Українізатор») shows no fan part and no link.

«Не так»: the link opens a ZoG «Ошибка» page; Stray shows a fan part; an error message in Telegram. A weekly ZoG check, a changed layout and a real new patch cannot be seen live — the tests show them.
