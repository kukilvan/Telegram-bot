# 03: IGDB, Steam и даты игр — клиенты, адаптер, `games.py`

**Сложность:** сложный (чужой API с токеном и ошибками, дат шесть точностей, регионы, обратная совместимость, пропавшая дата)
**Статус:** открыт

Спека: `../spec.md`, разделы 1 (что проверено), 4 (источник: клиент, поиск, снимок, название и описание, жанры, обложки), 5 (даты выхода), 15 («Клиент и адаптер», «Даты»). Термины — `CONTEXT.md` («Примерная дата», «Ранний доступ», «Обратная совместимость», «Издание»), стандарты — `docs/coding-standards.md` (правила 1, 2, 5, 6, 7, 9).

**Blocked by:** 02 (`platforms.py`: платформы, их номера IGDB, старшие, страны и порядок регионов)

Здесь нет ни типа игры в ядре, ни миграции, ни страниц: тикет делает **источник и чистую логику дат**, с тестами на сохранённых ответах. Подключает источник к `Tracker` тикет 04.

## Что сделать

- **Фикстуры:** нужные файлы из `.scratch/games-1-list-and-releases/igdb-answers/` — в `tests/fixtures/igdb/` (девять игр и три поиска). Ответы Steam `appdetails` (русское название латиницей и кириллицей, русское описание, `success: false`) — сохранить в `tests/fixtures/steam/` (форма — по спеке 4.4; можно снять настоящие, ключей не нужно). Тесты без сети.
- **Клиент IGDB** `app/providers/igdb.py` (спека 4.1): `IGDBProvider(client_id, client_secret)`, `enabled` — оба не пустые; токен Twitch берётся при первом запросе и живёт в памяти до срока (минус минута); ответ `401` — новый токен и один повтор; сбой — `IgdbError(status, cause)` (отказ Twitch в токене `400/401/403` → `status=401`; пустой список — не сбой); опрос — пауза и предел в минуту, `429` — ожидание и до 3 повторов; **поиск вне очереди опроса** (не ждёт, но учитывается; на `429` не повторяется). `failures.source_name`: `igdb` → «IGDB», причина `401` — «IGDB не принял ключ — проверьте ключ в настройках»; таймаут, нет соединения, `429`, `5xx` разбирает `failures.reason_of`.
- **`SourceNotConfigured`** (`errors.py`, пере-экспорт из `core`): без ключей любой запрос адаптера бросает его **без сети**.
- **Клиент Steam** `app/providers/steam.py` (спека 4.4): `app_details(appid)` — `appdetails?appids=…&l=russian&filters=basic`, таймаут 15 с, сбой или `success: false` → `None` и запись `info` в журнал. Старый поиск и страницы магазина не трогать (они понадобятся части 6.2), но лишнего не оставлять.
- **Адаптер** `app/tracker/sources/igdb_games.py` (спека 4.2–4.6), по образцу `tmdb_movies.py`:
  - **подсказки:** запрос из 4.2, удаление `"` и `\`, пустой запрос — подсказок и запроса нет; фильтр «только сами игры» (виды 0, 4, 8, 9, 10, 11 и нет `version_parent`) проверяется у ответа ещё раз; `Suggestion` (русское название IGDB → иначе `name`, `original_name`, год из `first_release_date` по UTC, обложка, новая строка `details` — платформы трекера через запятую в порядке «ПК, PS5, PS4, Xbox Series X|S, Xbox One, Switch 2, Switch»; нет ни одной — строки нет); порядок — как у IGDB; поле `details` добавляется в `Suggestion` (у остальных типов пусто);
  - **снимок** `GameSnapshot` (4.3): запрос на игру, состояние `source_snapshots.state` (`steam_id`, `ps_concept` — только число, `platforms` — только известные таблице, по возрастанию, `releases` — `full` / `early` / `cancelled`, прочие виды не берутся); пустой ответ — `TitleNotFound` / `failures.TitleGone`;
  - **название и описание** (4.4): русское IGDB (пометка «russian» без учёта регистра) → название Steam с русской буквой → `name` IGDB; описание — `short_description` Steam с русской буквой (без тегов, раскрытые `&quot;` и подобные, пробелы сжаты) → `summary` IGDB → пусто. Steam спрашивается **только при добавлении** (метод добавления с русскими текстами — имя решает сессия; опрос названия и описания не меняет);
  - **жанры:** перевод по таблице 4.5, неизвестный жанр — как есть;
  - **обложка:** полный адрес `https://images.igdb.com/igdb/image/upload/t_cover_big/<image_id>.jpg`, нет — `None`.
- **`app/tracker/games.py`** (новый, чистый; спека 5): `GameDate` (день, месяц, квартал, год, нет; текст `"2027-03-12"` / `"2027-03"` / `"2027-Q4"` / `"2027"` / `null`; подписи «12 марта 2027», «март 2027», «4 квартал 2026», «2027», «дата не объявлена»; начало и конец периода; «точная» — только день); разбор ответа IGDB мягкий (`sources/dates.py`: мусор — «даты нет»; `y`/`m` из `date`, если их нет — поле `date` у даты без дня не начало периода), разбор своего текста строгий (`ValueError`; день — через `parse_date`); выбор записи по региону (мир → первый и второй регион страны → самая ранняя, «не объявлена» последней; два одного региона — та, чьё начало раньше; **страна приходит параметром**, правило 2); платформа есть у игры (своя или старшая в `platforms` или записях); дата вида — своя или старшей по началу периода, при равенстве своя, «не объявлена» проигрывает, у взятой у старшей — пометка «версия для PS4»; отмена (есть `cancelled`, нет `full` и `early`); пропавшая дата (спека 5.4: нет ни одной записи вида в новом ответе → записи из прошлого снимка переносятся; исключение — появилась отмена; «TBD» — это запись и заменяет). Строки карточки и интервал проверки (6.6) этот тикет не делает — они в тикетах 04 и 05; здесь только то, что описано в разделе 5.
- **Документация:** `docs/code-map.md`, `docs/tests-map.md`; `docs/coding-standards.md` — строки `games` в таблице правила 7; `PROJECT_CONTEXT.md` — состояние (тикет 03 сделан; видимого нет), раздел 11 меняется только в последнем тикете; «Следующий шаг» меняет только «ОК».

## Критерии

Все тесты — на сохранённых ответах, без сети (спека 15).

- [ ] Поиск: «the witcher 3» без фильтра даёт **одну** подсказку (издания, бандлы, DLC, мод, обновление отсеяны адаптером), «ведьмак» — пять, с русскими названиями IGDB; строка платформ в нужном порядке; `"` и `\` удалены, запрос из кавычек — запроса нет; поиск не ждёт паузы опроса и на `429` не повторяется; опрос на `429` повторяет.
- [ ] Токен: первый запрос получает токен, второй — нет; `401` — новый токен и один повтор; отказ Twitch — причина «IGDB не принял ключ…»; таймаут и `5xx` — свои причины `failures`; без ключей — `SourceNotConfigured` без обращения к сети.
- [ ] Снимок: все девять игр превращаются в состояние 4.3 (виды `full`/`early`/`cancelled`, регионы, «TBD» как `null`, отмена у Prince of Persia, номер Steam, концепция PS — только число, только знакомые платформы); жанры переведены; обложка; название и описание по 4.4 во всех четырёх случаях (русское IGDB; Steam с русскими буквами; Steam латиницей не берётся; Steam не ответил).
- [ ] BUG-15 (часть): даты платформ **есть в снимке** игры (проверяется тест — «дата сохраняется»; показ в карточке — тикет 05).
- [ ] `GameDate`: подписи и периоды пяти точностей; `y`/`m` из `date`; строгий разбор своего текста (мусор — `ValueError`), мягкий разбор ответа (мусор — «даты нет»).
- [ ] Выбор по региону: Yomawari и Bloodborne для Израиля и США (разные регионы — разные даты); Hades II — ранний доступ и полный выход; обратная совместимость — Bloodborne (PS5 «27 марта 2015, версия для PS4»), «Ведьмак 3» (PS5 → дата PS4 2015, Switch 2 → дата Switch 2021); «не объявлена» проигрывает; отмена; пропавшая запись переносится, «TBD» заменяет, отмена не переносит.
- [ ] Правила стандартов: 1 (клиенты async), 2 (страна приходит параметром), 5 (тексты причин — в одном месте), 6 (всё по платформам — из таблицы), 7 (размер модулей), 9 (строгий/мягкий разбор).
- [ ] `pyflakes app tests` чистый; набор тестов зелёный.
- [ ] Для владельца: видимого в браузере и Telegram нет, ничего проверять не нужно — сессия показывает прохождение тестов и таблицу «игра → платформы → дата» для Bloodborne и «Ведьмака 3»; бота сессия перезапускает и убеждается по `/health` и журналу, что запуск без красного текста.
