## Что сделать

- **`list_titles(…, query=None, genre=None)`** (спека 5.1) в `listing.py`: `query` — подстрока названия или оригинального названия без учёта регистра, «ё» как «е», пробелы по краям обрезаны (тот же ключ, что у «По названию»), пусто — без поиска, сравнение в Python одним чтением, источники не спрашиваются; `genre` — склеенное имя (ниже); новые порядки `ListOrder.SCORE` («По оценке»: видимая оценка по точному значению от высокой к низкой, без оценки в конце, при равной — по `status_changed_at` от нового, затем по номеру от большего) и `ListOrder.ARCHIVED` («Сначала недавние»: по `status_changed_at` от нового, при равенстве — по номеру от большего). Вызов без аргументов (бот) — как был.
- **`TitleSummary`** (спека 2.5): `score` — видимая оценка, округлённая до деления (или нет), и `score_by_seasons`; оценки сезонов всех тайтлов строк читаются одним запросом, не по запросу на тайтл. Порядок по оценке считается по точному значению, не по округлённому.
- **Жанры** (спека 5.3): склейка по ключу (регистр, «ё» как «е», пробелы по краям); подпись склеенного — первое по алфавиту из написаний, с заглавной первой буквы («драма» и «Драма» → «Драма»); `genres(kind=None, statuses=None)` — склеенные жанры под фильтрами типа и статуса (не под поиском и не под самим жанром), по алфавиту, одним чтением. «Боевик», «Экшен», «Боевик и Приключения» остаются тремя жанрами (KI-30).
- **`app/web/archive.py`** (спека 5.4, 1.2): `GET /archive?q=…&kind=…&genre=…&status=…&order=…` и фрагмент `GET /archive/results?…`. Заголовок «Архив», поле «Название» с кнопкой «Найти», ряды ссылок (выбранная — `aria-current`, неизвестное значение — как без него): тип — Все · Фильмы · Сериалы · Аниме; жанр — Все жанры · (жанры архива по алфавиту; жанра нет среди жанров архива — как без фильтра); статус — Весь архив · Просмотрено · Бросил (`watched`, `dropped` — значения `TitleStatus`, строк в шаблоне нет); порядок — По оценке (по умолчанию) · Сначала недавние (`archived`) · По названию (`name`). Строки — общий макрос Списка с постером, значком типа, названием, годом и статусом, справа оценка («9+»; среднее по сезонам — с пометкой «ср.»; нет оценки — пусто); вся строка — ссылка на карточку; над строками «Показано N тайтлов». Пусто: архив пуст — «В архиве пока ничего нет. Сюда попадает просмотренное и брошенное»; под фильтром — «Под этот фильтр ничего не подходит» и «Сбросить фильтры». Режима «Удалить несколько» в Архиве нет. Заглушка «Архив» в `app/web/menu.py` уходит.
- **Поле поиска** (спека 5.2, общее для Архива и Списка): запрос уходит через 300 мс после последней буквы, с первой буквы, обрезается до 100 знаков; HTMX `GET …/results` с текущими фильтрами, `hx-sync="…:replace"` (старый запрос отменяется новым); ответ — фрагмент с фильтрами, «Показано N …» и строками (поле ввода в него не входит — курсор не теряется); заголовок `HX-Push-Url` с адресом страницы и запросом (закладка и «Назад» работают). Без HTMX — обычная форма `GET` той же страницы, скрытые поля несут фильтры. Ссылки фильтров и порядка несут `q`; поиск несёт фильтры и порядок. Ничего не нашлось — «Ничего не нашлось по запросу «…»» и «Сбросить поиск» (тот же адрес без `q`).
- **Список** (`title_list.py`, спека 5.5): то же поле поиска над фильтрами, `GET /list/results`; `q` в адресе, во всех ссылках, в режиме выбора и в итоговом адресе удаления нескольких; оценка справа в строке, если её видно; порядки Списка не меняются.
- **Документация:** `docs/code-map.md`, `docs/tests-map.md`; `PROJECT_CONTEXT.md` — состояние (тикет 03 сделан) и раздел 4 (что проверять: Архив, поиск в Списке); «Следующий шаг» меняет только «ОК».

## Критерии

Тесты — по разделу 9 спеки; без сети.

- [ ] Ядро: поиск (регистр, «ё», оригинальное название, пробелы по краям, пусто — все); фильтр жанра со склейкой; `genres` под фильтрами типа и статуса; порядок по оценке (без оценки в конце, при равной — недавние выше, точное среднее важнее округлённого), «Сначала недавние», «По названию»; вызов без аргументов — как раньше; оценка в строке (своя, среднее, нет); число запросов не растёт с числом тайтлов.
- [ ] Веб, Архив: ряды ссылок с выбранным, ссылки несут остальные параметры и `q`; неизвестные значения и несуществующий жанр — как без них; фрагмент результатов с `HX-Push-Url`; оценка в строке (своя, «ср.», пусто); оба пустых состояния и «Ничего не нашлось»; без HTMX — форма; вся строка — ссылка.
- [ ] Веб, Список: `q` в адресе, ссылках, режиме выбора и итоговом адресе удаления; оценка в строке.
- [ ] Экранирование: название и запрос с `<script>` и кавычками выводятся текстом в Архиве и Списке.
- [ ] Правило 10: `archive.py` — только фасад и разрешённые чистые модули; адреса Архива без входа закрыты; заглушки Архива в меню нет.
- [ ] `pyflakes app tests` чистый; набор тестов зелёный.
- [ ] Пошаговая проверка для владельца (формат — `CLAUDE.md`): `http://localhost:8080/archive` — просмотренное и брошенное, по умолчанию с высокой оценкой выше; в поле «Название» набрать «дюн» — список сменяется по ходу набора, адрес в строке браузера меняется, «Назад» возвращает прежний; фильтры типа, жанра и статуса и три порядка («По оценке», «Сначала недавние», «По названию») меняют список; оценка справа в строке; на `http://localhost:8080/list` поле «Название» работает так же и сохраняется в режиме «Удалить несколько»; окно сузить — строки читаются в один столбец.
