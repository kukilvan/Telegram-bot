## Что сделать

Поведение и адреса части 5.1 не меняются; владелец после тикета видит тот же каркас. Появляется то, на чём строятся остальные тикеты.

- **Модули `app/web/`** (спека 1.1): сейчас всё, кроме `auth.py`, `status_line.py` и `server.py`, лежит в `app/web/app.py` (213 строк). `create_web_app` остаётся только сборкой: слои (заголовки и `Origin`, сессия, проверка входа), вход и выход, `/health`, строка живых данных, подключение роутеров (`APIRouter`) страниц, 404, `/static`. Заглушки Ленты, Архива и Настроек переезжают в `app/web/menu.py` вместе с `SECTIONS` и `OPEN_ADDRESSES`; оба — типы с именованными полями (`Section`: адрес, имя в коде, подпись, фраза заглушки или её отсутствие; открытый адрес: имя, флаг «открыт и без пароля»). Заглушки «Список» и «Поиск» остаются, пока их не заменят 03 и 05; у заглушки Архива фраза из спеки 1.2.
- **`app/web/pages.py`** (спека 1.3, 1.4): вывод страницы с меню, строкой живых данных и одноразовой строкой-уведомлением (через сессию, до 300 знаков, показалась — стёрлась); вывод фрагмента; ответ «тайтла нет» (фрагмент «Этого тайтла больше нет в списке» со ссылкой «Открыть Список» и страница `404` с тем же текстом); правила ответа на нажатие: HTMX (`HX-Request`) — фрагмент и `200` даже для ошибки, без HTMX — `303`, переход через HTMX — `200` с `HX-Redirect`; обёртка «неожиданная ошибка»: запись в журнал с трассировкой и фрагмент «Не получилось. Попробуйте ещё раз; подробности — в журнале» (`200`), для страницы — общий шаблон с тем же текстом и `500`.
- **`app/web/posters.py`** (спека 1.5): адрес картинки по сохранённому значению и размеру (`/…` → `https://image.tmdb.org/t/p/<размер><имя>`; `https://…` — как есть; иное и пустое — нет постера); размеры `w92` и `w342`; список разрешённых сайтов картинок для заголовка.
- **`Content-Security-Policy`** (спека 1.5): добавляется `img-src 'self' https://image.tmdb.org <адрес Shikimori> <его поддомены>`; адрес — начало `SHIKIMORI_BASE_URL`; `create_web_app` получает список из `app/main.py`; других внешних адресов нет.
- **Макрос строки тайтла** (спека 1.1, 1.5, 1.6): постер в рамке со значком типа 🎬/📺/🎌 под картинкой (не загрузилась — виден значок; пустой `alt`, ширина, высота, `loading="lazy"`), значок типа, название, оригинальное название (мельче), год — один макрос для подсказок и Списка.
- **Обновление постера опросом** (спека 1.5, «Обновление»): при каждой удачной проверке собственного источника фильма, сериала, аниме опрос записывает `poster_path` из свежего ответа, если он непустой и отличается от сохранённого; пустой не стирает; проверка продолжений постер не трогает. Запись — в той же сессии записи, что и остальное состояние проверки (правило 9). Источники фильмов, сериалов и аниме уже читают постер в снимке (`poster_path`).
- **Стили** (спека 1.6): `style.css` дописывается — строка с постером слева, текст справа, кнопка справа; ниже 40rem один столбец, кнопки во всю ширину; нажимаемая область не меньше 44 px; класс `htmx-request` (две вложенные подписи в кнопке, одна видна во время запроса; `hx-disabled-elt` ставят страницы). Светлая и тёмная тема как в 5.1; без внешних шрифтов и скриптов.
- **Правило 10** в `docs/coding-standards.md` (спека 1.1, последний абзац): «Страница (или раздел) — свой модуль `app/web/` со своим роутером; `create_web_app` только собирает».
- **Документация:** `docs/code-map.md`, `docs/tests-map.md`; `PROJECT_CONTEXT.md` — только состояние и раздел 5 (карта модулей веба); «Следующий шаг» меняет только «ОК».

## Критерии

Тесты — по разделу 8 спеки; без сети.

- [ ] Все старые тесты веба проходят без правки (поведение 5.1 не изменилось): вход, блокировка, `Origin`, меню из пяти разделов, строка живых данных, `404`.
- [ ] Правило 10: тест разбирает импорты всех `app/web/*.py` (включая новые модули); каждый зарегистрированный адрес приложения, кроме `OPEN_ADDRESSES`, без входа не отдаёт страницу.
- [ ] Заголовок безопасности: `img-src` — ровно `'self'`, `https://image.tmdb.org`, адрес Shikimori из настройки и его поддомены; других внешних адресов нет; при другом `SHIKIMORI_BASE_URL` заголовок меняется.
- [ ] Постер: адрес TMDb нужного размера, адрес Shikimori как есть, пустое и значение без `https://`/`/` — значок; у `<img>` пустой `alt`, `width`, `height`, `loading="lazy"`.
- [ ] Страница: уведомление показывается один раз и стирается; длинное усекается до 300; нажатие через HTMX — фрагмент `200`, без HTMX — `303`, переход через HTMX — `200` + `HX-Redirect`; «тайтла нет» — фрагмент и `404`-страница; неожиданная ошибка — запись в журнал и текст, `200` у фрагмента и `500` у страницы.
- [ ] Шаблоны: нет встроенных `<script>`, `style=`, `on…=`, `hx-on`, `js:`, `hx-confirm`, `http://`, `https://`; единственный скрипт страницы — `/static/htmx.min.js`; название с `<script>` и кавычками выводится текстом (макрос строки тайтла).
- [ ] Опрос: удачная проверка записывает новый непустой постер фильма, сериала, аниме; пустой ответ его не стирает; проверка продолжений не трогает.
- [ ] `pyflakes app tests` чистый; набор тестов зелёный.
- [ ] Пошаговая проверка для владельца (формат — `CLAUDE.md`): остановить → обновить файлы → `.\start-bot.ps1`; `http://localhost:8080` → войти; меню из пяти разделов и строка живых данных работают как раньше; «Архив» показывает новую фразу про Список и фильтры «Просмотрено»/«Бросил»; окно браузера сузить до половины экрана — страница читается, кнопка «Выйти» нажимается; в Telegram бот отвечает на «📚 Мои тайтлы» как раньше. Постеров здесь ещё не видно (они появятся в тикетах 02 и 03).
