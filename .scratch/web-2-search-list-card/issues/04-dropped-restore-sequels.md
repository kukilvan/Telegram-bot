## Что сделать

- **Слова в `CONTEXT.md`** (спека 2.10) — до правки кода: «Карточка» (`card`), «Вернуть в список» (`restore`), «Продолжение» (`sequel`); строка про «Бросил» — «`dropped`», «Пройдено» пока в коде не заведено.
- **Статус** (спека 2.2): `TitleStatus.DROPPED = "dropped"`, подпись «Бросил» в `STATUS_LABELS`, `ARCHIVE_STATUSES = {WATCHED, DROPPED}` рядом с `TitleStatus`. «Бросил» не входит в `progress.AUTOMATIC_STATUSES` и в `POLLED_STATUSES`; строка про «статус, который владелец ставит сам» в `progress.py` обновляется. Строки `"dropped"` нет вне `models.py` и миграций (правило 6).
- **`mark_dropped(title_id)`** (спека 2.3) в `statuses.py`: одна сессия записи — нет тайтла `UnknownTitle`; уже «Бросил» — «не изменилось»; статус «Бросил», момент смены статуса — сейчас, слежение выключено; снимок проверки продолжений удалён; ещё не доставленные записи очереди этого тайтла удалены (в том числе сообщения о сбое источника), события остаются. Галочки и «Отметить все вышедшие» у брошенного работают, статус остаётся «Бросил».
- **Миграция `0010`** (спека 2.4): колонка `titles.restored_at` (naive UTC, пусто — не возвращали); идёт с нуля и на готовой базе, откатывается; копию базы перед ней приложение делает само.
- **`restore_title(title_id)`** (спека 2.4) в `statuses.py`: нет тайтла — `UnknownTitle`; статус не из архива — «не изменилось»; сериал или аниме «Просмотрено» — тоже (сезонный ли тайтл — из `KINDS` `is_seasonal`, не сравнением типа). Фильм: «Хочу», слежение включено, снимок продолжений удалён. Сериал и аниме из «Бросил»: «Хочу», слежение включено, затем `storage.refresh_status`. Записывается `restored_at`, время следующей проверки собственного источника — сейчас.
- **Первая проверка после возврата — точка отсчёта** (спека 2.4): при выборке тайтлов для опроса у тайтла с `observed_at < restored_at` у `DueTitle` ставится признак (предложение: `baseline`); `Poller.record_all` в этом случае сохраняет свежее состояние (сезоны, серии, даты, постер, пересчёт статуса), но событий не ставит; после такой проверки `observed_at` новее момента возврата. Сбой источника момента не сдвигает. Проверка продолжений признаком не затрагивается. Журнал: «title N: first check after return, recorded as the baseline». Пропуск — в одном месте (`record_all`).
- **Данные карточки: продолжения** (спека 2.9): у «Просмотрено» фильма со снимком проверки продолжений — проверена ли коллекция (в снимке есть `parts`) и строки продолжений (те, что `Sequels.is_sequel` считает продолжениями, по дате, без даты — в конце): id в TMDb, название, дата, номер тайтла в списке (по известным id фильмов — из 03). Чистая функция в `cards.py`, без базы.
- **`app/web/card.py` дополняется** (спека 1.2, 4.3–4.5): `POST /titles/{id}/dropped`, `POST /titles/{id}/restore`, `POST /titles/{id}/sequels` (`kind` — скрытое поле из карточки, `sequel_id`). Кнопки по таблице 4.3 целиком: фильм «Хочу» — «Посмотрел», «Бросил», «Удалить»; сериал и аниме «Хочу»/«В процессе»/«Жду»/«Досмотреть» — «Бросил», «Удалить»; фильм «Просмотрено» — «Вернуть в список», «Удалить», блок «Продолжения»; сериал и аниме «Просмотрено» — «Удалить» и строка про снятие галочки; любой «Бросил» — «Вернуть в список», «Удалить». Подтверждения «Посмотрел», «Бросил», «Вернуть» не просят; нажатие, которое ничего не изменило, — свежая карточка.
- **Блок «Продолжения»** (спека 4.5): не проверено — «Ищу продолжения в коллекции TMDb — обновите страницу через минуту»; нет — «Продолжений пока нет. Проверяю раз в неделю»; иначе строки: название, дата («15 декабря 2028» или «дата не объявлена»), справа «В списке» (ссылка на карточку) или кнопка «Следить» (`follow_sequel_of`, «Добавляю…», удачно — свежая карточка, остаёмся на ней; ошибка источника — строка в блоке, как в 3.4 тикета 03).
- **Бот** (спека 6): карточка бота показывает «Бросил» (из `STATUS_LABELS`); «Мои тайтлы» не меняется; кнопок «Бросил» и «Вернуть» в боте нет; у брошенного сериала «Просмотренные сезоны» работают, статус остаётся «Бросил»; «Посмотрел» под старым сообщением о брошенном фильме делает его «Просмотрено».
- **Документация:** `docs/code-map.md`, `docs/tests-map.md`; `PROJECT_CONTEXT.md` — состояние и раздел 4 (что проверять: «Бросил», «Вернуть», «Следить»); `CONTEXT.md` — слова выше; «Следующий шаг» меняет только «ОК».

## Критерии

Тесты — по разделу 8 спеки; без сети.

- [ ] «Бросил» из каждого статуса; повторное — «не изменилось»; опрос брошенный тайтл не проверяет; галочка у брошенного ставится, статус «Бросил»; очередь: недоставленные записи тайтла удалены, события на месте, тот же факт после «Вернуть» снова не приходит; у «Просмотрено» фильма снимок продолжений удалён.
- [ ] «Вернуть в список»: фильм из «Просмотрено» и из «Бросил» — «Хочу», слежение, снимка продолжений нет, проверка назначена на сейчас, `restored_at` записан; сериал из «Бросил» — статус по галочкам (закрытый со всеми отметками — «Просмотрено»); «Просмотрено» сериал и статус не из архива — «не изменилось».
- [ ] Первая проверка после возврата: состояние источника изменилось (объявлена и прошла дата фильма; вышли серии и анонсирован сезон у сериала и аниме) — новое состояние сохранено, событий нет; следующая проверка с новым фактом — событие есть; неудачная первая проверка не снимает признак; проверка продолжений признаком не затронута.
- [ ] «Посмотрел» после «Вернуть в список» — без ошибки уникального ключа, первый взгляд на продолжения без событий.
- [ ] Миграция `0010`: с нуля, на готовой базе, откат; правило 6: `"dropped"` вне `models.py` и миграций нет (существующий тест дополнен); у каждого статуса есть подпись.
- [ ] Продолжения: не проверено, пусто, строки с «В списке» и без, порядок по дате (без даты в конце); блок только у «Просмотрено» фильма.
- [ ] Карточка: ровно кнопки таблицы 4.3 для каждого сочетания типа и статуса; нажатия вызывают нужные методы и отвечают свежей карточкой (`303` без HTMX); `UnknownTitle` — «больше нет в списке»; «Следить» — свежая карточка, источник не ответил — строка в блоке.
- [ ] Бот: «Бросил» в карточке бота; «Мои тайтлы» без изменений; старая кнопка «Посмотрел» у брошенного фильма работает.
- [ ] `pyflakes app tests` чистый; набор тестов зелёный.
- [ ] Пошаговая проверка для владельца (формат — `CLAUDE.md`): добавить в вебе фильм из коллекции (например «Дюна») → «Посмотрел» → блок «Продолжения» («Ищу…», через минуту — строки) → «Следить» у продолжения → строка стала «В списке»; «Вернуть в список» у просмотренного фильма — статус «Хочу», блока «Продолжения» нет; у сериала «Бросил» → статус «Бросил», галочку сезона поставить можно, статус не меняется; «Вернуть в список» — статус по галочкам; в Telegram: «📚 Мои тайтлы» видит брошенное, карточка бота показывает «Бросил»; через пару минут после возврата в Telegram не приходит лавина сообщений о том, что случилось в архиве.
