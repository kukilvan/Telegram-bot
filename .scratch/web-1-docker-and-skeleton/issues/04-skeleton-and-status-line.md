# 04: Каркас страниц и строка живых данных

**Сложность:** средний
**Статус:** открыт

Спека: `../spec.md`, разделы 3.6–3.9, 5 (`docs/coding-standards.md`, правило 10), 6 («Каркас и данные»). Термины — `CONTEXT.md`.

**Blocked by:** 03 (вход и защита запросов)

## Что сделать

- **`Tracker.overview()`** → `Overview(title_count: int, last_check_at: datetime | None)` в `results.py` (спека 3.7): работа в модуле `titles` (список), в потоке (правило 1); число — все тайтлы в базе, включая архив; `last_check_at` — самый поздний `source_snapshots.observed_at`, уже на часах владельца (пояс правил доставки: настройка, иначе `BOT_TIMEZONE`), читается в той же сессии (правило 2); неудачная проверка момент не двигает. Метод — в фасаде `core.py`; другого входа в ядро у веба нет.
- **Склонение «тайтл»**: сейчас `failures._titles_word` — сделать общей функцией проекта (копии нет), бот берёт её же.
- **Текст строки** (спека 3.7): «В списке 12 тайтлов · последняя проверка источников в 14:05»; 0 — «В списке пока нет тайтлов»; сегодня «в 14:05», вчера «вчера в 23:10», раньше «26 окт в 09:05», другой год «26 окт 2025 в 09:05»; проверок не было — «источники ещё не проверялись»; формат и короткие месяцы — как в карточках бота (`cards.py`, без копии). База не ответила — «нет данных из базы» и запись в журнал; страница всё равно открывается (не `500`).
- **Общий шаблон и заглушки** (спека 3.6): `<html lang="ru">`, `viewport`, заголовок «Трекер релизов», меню Лента (`/`), Список (`/list`), Архив (`/archive`), Поиск (`/search`), Настройки (`/settings`) с `aria-current="page"` у текущего; кнопка «Выйти» (форма `POST /logout`); строка живых данных; пять заглушек с фразами из таблицы 3.6. Вид простой, читается на ПК и на телефоне (на узком экране меню переносится), светлая и тёмная тема по `prefers-color-scheme`; без внешних шрифтов, CDN и картинок из интернета — `app/web/static/style.css` дописывается. Страница входа остаётся без меню и строки. Любой другой адрес за входом — `404`, «Страница не найдена» в общем шаблоне.
- **HTMX** (спека 3.8): `app/web/static/htmx.min.js` (2.x, лежит в проекте; версия и откуда взят — в `docs/code-map.md`); `<meta name="htmx-config">` с `includeIndicatorStyles: false`, `allowEval: false`. Строка живых данных раз в 60 с запрашивает `GET /status-line` и заменяется; сессия истекла — `401` с `HX-Redirect: /login`. В браузере проверить, что HTMX 2 выполняет `HX-Redirect` при ответе `401`; если нет — ответ `200` с тем же заголовком (и тест, и спека 3.7 меняются вместе с этим; записать в тикет).
- **Правило 10** в `docs/coding-standards.md` (спека 3.9): страницы ходят в ядро только через фасад `Tracker`; из `app/tracker/` веб импортирует только `core` и чистые модули без базы и сети (`cards`, `kinds`, `models` ради перечислений); вход проверяется в одном месте.
- Документация: `docs/code-map.md` (модули `app/web/`, версия HTMX), `docs/tests-map.md`, `PROJECT_CONTEXT.md` (состояние, раздел 5).

## Критерии

Тесты — по разделу 6 спеки («Каркас и данные»).

- [ ] Каждая заглушка за входом — `200`, меню с пятью разделами, текущий выделен, кнопка «Выйти»; несуществующий адрес за входом — `404` в общем шаблоне.
- [ ] `Tracker.overview()`: пустая база — 0 и `None`; тайтлы и снимки — число и самый поздний `observed_at` на часах владельца (пояс из настройки и из `default_tz`).
- [ ] Текст строки: склонение (0, 1, 2, 5, 11, 21), «в 14:05», «вчера в …», «26 окт в …», другой год, «ещё не проверялись»; сбой ядра — «нет данных из базы», страница `200`.
- [ ] `/status-line` за входом отдаёт фрагмент; без входа — `401` с `HX-Redirect`; страницы подключают `/static/htmx.min.js`, файл отдаётся; в шаблонах нет `http://`, `https://`, встроенных `<script>` и `style=`.
- [ ] Правило 10: тест разбирает импорты `app/web/` и проверяет, что адреса приложения, кроме закреплённого списка открытых, без входа не отдают страницу.
- [ ] Бот и веб берут склонение из одной функции (в коде нет второй копии).
- [ ] `pyflakes app tests` чистый; набор тестов зелёный.
- [ ] Пошаговая проверка для владельца: остановить (`.\stop-bot.ps1`) → обновить файлы → `.\start-bot.ps1`; `http://localhost:8080` → войти; видно меню из пяти разделов, текущий выделен, у каждого раздела заглушка «Скоро будет…»; строка «В списке N тайтлов · последняя проверка…» — число совпадает с «📚 Мои тайтлы» в Telegram; в Telegram добавить тайтл («➕ Добавить») — через минуту строка в браузере сама показывает новое число без перезагрузки страницы; страница читается в узком окне браузера (окно сузить мышью); «Выйти» возвращает на вход. Сообщить, как проверялся `HX-Redirect` (сессия истекла).
