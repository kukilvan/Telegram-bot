# 03: Страница Настроек и строка о Telegram

**Сложность:** средний
**Статус:** принят

Спека: `../spec.md`, разделы 1.1–1.2 (модули, адреса), 3 (страница, разбор формы, отказ), 4 (бот не подключён к Telegram), 7 (меню), 8 (строка о Telegram без ядра, пояс с `<script>`), 9 («Runtime», «Веб»: Настройки, строка о Telegram), 10 (документы). Термины — `CONTEXT.md`, стандарты — `docs/coding-standards.md` (правила 1, 6, 7, 10).

**Blocked by:** 01 (`pages.py` после переименований, макросы, обработка 405), 02 (`Tracker.settings()`, `save_settings()`, `SettingsChange`, `SettingsRefused`)

## Что сделать

- **`app/web/settings.py`** (новый, спека 1.2, 3): `GET /settings` (`settings`) — страница: «Настройки», форма, «Сейчас», «Бот в Telegram»; `POST /settings` (`settings_save`) — сохранить форму целиком: удачно — `303` на `/settings` со строкой «Сохранено» (один раз, `pages.notify`); отказ ядра — та же страница с кодом `400`. Форма обычная (`method="post"`), без HTMX.
- **`app/web/templates/settings.html`** (новый, спека 3.1): сверху вниз — заголовок; строка ошибки (`role="alert"`, только после отказа); форма: пояс (выпадающий список, первая строка — `default_label` со значением «», под списком — «Журнал бота пишет время по поясу из файла настроек запуска (Asia/Jerusalem)», если пояс отличается от `.env`), рабочие дни (семь галочек «Пн … Вс», значения 0…6, пояснение), час сводки (`<input type="time">`), тихие часы «с» / «до» (пояснение про одинаковое время), части сезона (`<input type="number" min="1" max="52" step="1">`, пояснение про аниме), кнопка «Сохранить» и строка «Новые правила действуют сразу, в том числе для того, что уже ждёт отправки»; затем «Сейчас»; затем «Бот в Telegram». У каждого поля `<label>`, нажимаемая область не меньше 44 px, узкий экран — та же одна колонка, галочки переносятся. Шаблон без сравнений значений (правило 6) и без встроенных скриптов и `style=`.
- **Разбор формы** (спека 3.2): веб передаёт ядру `SettingsChange` как есть; сам отбрасывает только чужие значения `workday` (не из «0»…«6»); нет поля — пустая строка.
- **Отказ** (спека 3.3): `SettingsRefused` → страница с кодом `400`, строка `text` сверху, у поля `field` — `aria-invalid="true"` и класс выделения, во всех полях — введённое (пояс, галочки, время, число), а не сохранённое; список поясов, подписи и «Сейчас» — из свежего `settings()`. Неожиданная ошибка — «Не получилось…» с «Обновить» (`guarded_with_refresh("settings")`).
- **Меню** (спека 7): у `Section` нет `phrase`; роутера заглушек и `section.html` больше нет; «Настройки» выделяются на своей странице (`aria-current`). `OPEN_ADDRESSES` не меняется.
- **`Health.telegram_down`** (спека 4): новое поле в `app/runtime.py`, сначала `False`; часть «бот» (`Runtime._run_bot`) ставит `True`, когда подключение или приём кончились ошибкой (ветка «бот: нет связи с Telegram, повтор через …»), и `False`, когда приём начался (`receiving_began`); во время остановки флаг не трогается; `/health` не меняется.
- **Строка о Telegram** (спека 4): `create_web_app(..., telegram_down: Callable[[], bool] = lambda: False)` и `WebContext.telegram_down`; `app/main.py` передаёт чтение `health.telegram_down`. Пока `True` — под строкой живых данных на каждой странице за входом: «Бот не подключён к Telegram — сообщения не приходят. Проверьте интернет и токен в файле .env; подробности — в журнале». Строка внутри `#status-line` (обновляется раз в минуту, `hx-swap="outerHTML"`; блок становится `<div id="status-line">`), класс предупреждения, без `role="alert"`. В Настройках в «Бот в Telegram» — та же фраза или «Подключён». Страница входа строки не показывает; страница без ядра (`tracker=None` в тестах) строку о Telegram показывает независимо от ядра.
- **`KNOWN_ISSUES.md`:** новая запись (KI-33) — «строка о Telegram не появляется при потере связи во время приёма» (aiogram 3 повторяет запросы сам внутри `start_polling` и наружу ошибку не отдаёт); формат записи — в начале файла.
- **Документация:** `docs/code-map.md`, `docs/tests-map.md`; `PROJECT_CONTEXT.md` — состояние (тикет 03 сделан; Настройки работают, заглушек в меню нет) и раздел 4 (что проверять: Настройки, строка о Telegram); «Следующий шаг» меняет только «ОК».

## Критерии

Тесты — по разделу 9 спеки; веб — `TestClient` с поддельным ядром (вид) и с настоящим ядром (путь «форма → база»); runtime — на поддельном боте; без сети.

- [ ] Показ: сохранённое и значения по умолчанию (поля, галочки, выбранный пояс, первая строка списка); строка про журнал — только при поясе не из `.env`; «Сейчас» на странице.
- [ ] Сохранение: `303`, «Сохранено» один раз; ядро получило `SettingsChange` с полями как в форме; чужие значения галочек отброшены; «Сохранить» без изменений — «Сохранено», в базе то же.
- [ ] Отказ: `400`, строка ошибки сверху, `aria-invalid` у нужного поля, введённое на месте, «Сейчас» по сохранённым правилам; неожиданная ошибка — «Не получилось» с «Обновить».
- [ ] Runtime: `telegram_down` сначала `False`; ошибка подключения — `True`; начало приёма — `False`; во время остановки не меняется.
- [ ] Строка о Telegram: при `telegram_down` — на странице и в ответе обновления `#status-line`, без — нет; в «Бот в Telegram» — «Подключён» / строка; страница входа — без неё.
- [ ] Правило 10: `settings.py` импортирует из ядра только разрешённое; `GET` и `POST /settings` закрыты без входа; `POST` с чужим `Origin` — `403`; шаблоны без встроенных скриптов и `style=`; в меню заглушек нет, `section.html` удалён.
- [ ] Экранирование: пояс из базы с `<script>` выводится текстом.
- [ ] `pyflakes app tests` чистый; набор тестов зелёный.
- [ ] Пошаговая проверка для владельца (формат — `CLAUDE.md`; бота сессия запускает сама): `http://localhost:8080/settings` — сохранить новый час сводки (строка «Сохранено», после обновления страницы на месте); ввести час сводки внутри тихих часов — красная строка сверху, введённое не пропало, прежние настройки не изменились; выбрать пояс — в «Сейчас» поменялось время; выбрать первую строку («Как в файле настроек запуска…») — выбор стёрт; окно сузить — одна колонка; в Telegram — «Проверка правил доставки» присылает событие по новым правилам; строка «Бот не подключён к Telegram» — сессия показывает её сама, временно испортив токен в `.env` и вернув его (значение не выводится).
