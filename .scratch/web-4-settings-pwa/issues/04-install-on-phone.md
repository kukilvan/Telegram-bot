# 04: Установка на ПК и iPhone — файл описания, значки, `<head>`, «← Назад»

**Сложность:** простой
**Статус:** принят

Спека: `../spec.md`, разделы 5 (всё: файлы, `<head>`, `Content-Security-Policy`, «← Назад», что увидит владелец), 8 (чужой `Referer`, значок при ненастроенном входе), 9 («Веб»: установка, «← Назад»; проверка владельцем), 10 (документы). Термины — `CONTEXT.md`, стандарты — `docs/coding-standards.md` (правила 6, 10).

**Blocked by:** 01 (шаблоны и макросы после уборки; `card.html` правится вместе с `pages.py`)

С тикетами 02 и 03 не связан; можно делать до или после них. Телефон владельца — iPhone: проверка в Safari на iPhone и в Chrome или Edge на ПК; строки для Android делаются, но проверяются только тестами.

## Что сделать

- **Файлы установки** в `app/web/static/` (спека 5.1) — папка открыта без входа (`OPEN_ADDRESSES`, `/static/`), `Cache-Control: no-store` на ней нет:
  - `manifest.webmanifest` — ровно как в спеке (`id` / `start_url` / `scope` — `/`, `display: standalone`, имя «Трекер релизов», короткое «Трекер», цвета `#f6f6f4`, три значка); тип ответа `application/manifest+json` (если сервер статики отдаёт другой — задать).
  - `icons/icon.svg`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png` (180), `favicon-32.png` (32). **Картинка:** квадрат во всю площадь цвета `--accent` светлой темы (`#2b5fd9`), по центру белый знак — листок календаря со знаком «▶» внутри, знак целиком в круге диаметром 80 % стороны; фон непрозрачный. PNG делаются из `icon.svg` один раз (любым способом, например снимком в Edge без окна); способ — одной строкой в `docs/code-map.md`.
- **Строки в `<head>`** (спека 5.2): в `base.html`, значит на всех страницах, включая страницу входа — `manifest`, `icon` (SVG и 32 px), `apple-touch-icon`, два `theme-color` (светлый `#f6f6f4`, тёмный `#161615`), `mobile-web-app-capable`, `apple-mobile-web-app-capable`, `apple-mobile-web-app-title` («Трекер»), `apple-mobile-web-app-status-bar-style` (`default`) — текст строк в спеке.
- **`Content-Security-Policy`** (спека 5.3) не меняется; тест закрепляет, что в заголовке нет `manifest-src`, отличного от `'self'`, а `<link rel="manifest">` ведёт на свой адрес.
- **«← Назад» в карточке** (спека 5.4), в `card.html` над карточкой вне блока `#card` (нажатия его не трогают): `Referer` с того же `Host` и путь `/`, `/list`, `/archive` или `/search` (со своей строкой запроса) → «← Назад» на этот путь, Список возвращается с фильтрами; иначе → «← Список», а у тайтла в архиве (`ARCHIVE_STATUSES`) — «← Архив». Решение о ссылке принимает Python (`card.py` / `pages.py`), шаблон только выводит готовую ссылку и подпись (правило 6); чужой хост, путь `/titles/2`, `/settings`, путь с `//` — запасная ссылка.
- **Документы:** `docs/code-map.md` (файлы установки и способ изготовления значков), `docs/tests-map.md`; `PROJECT_CONTEXT.md` — состояние (тикет 04 сделан; все тикеты части 5.4 сделаны, дальше — код-ревью) и раздел 4 (как поставить на ПК и iPhone, «← Назад»); «Следующий шаг» меняет только «ОК».

## Критерии

Тесты — по разделу 9 спеки; веб — `TestClient`; без сети. PNG проверяются по заголовку (ширина и высота), без Pillow.

- [ ] `GET /static/manifest.webmanifest` без входа — `200`, `application/manifest+json`, без `no-store`, JSON с полями раздела 5.1, `start_url` и `scope` — `/`.
- [ ] Каждый значок из файла описания и из `<head>` отдаётся без входа, это PNG нужного размера (192, 512, 512, 180, 32), `icon.svg` отдаётся как SVG.
- [ ] `<head>` страницы входа и страницы за входом содержит все строки раздела 5.2; страница «Вход не настроен» (`WEB_PASSWORD` пуст) тоже, значки и файл описания отдаются.
- [ ] `Content-Security-Policy` как был: нет `manifest-src`, отличного от `'self'`.
- [ ] «← Назад»: `Referer` Ленты, Списка с фильтрами, Архива, Поиска — ссылка на него; без `Referer`, с чужим хостом, с `/titles/2`, с `/settings`, с `//` — «← Список» (у архивного тайтла — «← Архив»); ссылка вне `#card`.
- [ ] Экранирование: название с `<script>` в карточке по-прежнему текстом; в запасной ссылке строка запроса из `Referer` экранирована.
- [ ] Правило 10: `OPEN_ADDRESSES` не менялся; шаблоны без встроенных скриптов и `style=`.
- [ ] `pyflakes app tests` чистый; набор тестов зелёный.
- [ ] Пошаговая проверка для владельца (формат — `CLAUDE.md`; бота сессия запускает сама, `WEB_HOST=0.0.0.0` в `.env` у владельца включён): **ПК, Chrome или Edge** — `http://localhost:8080`, в адресной строке «Установить приложение» (у Edge — «Приложение доступно») → «Трекер релизов» открывается своим окном со значком в «Пуске»; **iPhone, Safari, дома** — `http://<адрес ПК>:8080` → «Поделиться» → «На экран „Домой“» (в iOS 26 переключатель «Открыть как веб-приложение» включён) → «Добавить»; на экране значок «Трекер» с картинкой приложения; открывается без адресной строки; первый запуск — страница входа (у значка свои cookie, отдельно от Safari); в Списке открыть карточку → «← Назад» возвращает в Список с теми же фильтрами; цвет верхней полосы совпадает с фоном страницы. Если iPhone открывает значок во вкладке Safari, а не своим окном — это не ошибка части (полная установка требует `https://`, кусок 7): владелец сообщает, сессия записывает в `KNOWN_ISSUES.md`.
