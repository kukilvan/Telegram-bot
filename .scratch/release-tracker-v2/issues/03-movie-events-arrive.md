# 03: События фильма приходят в Telegram

**Сложность:** сложный (движок событий, дедупликация, расписание опроса)

**What to build:** ядро само опрашивает фильмы по расписанию и присылает события: дата премьеры объявлена, перенесена («15 дек 2026 → 22 янв 2027»), фильм вышел в кино, вышел цифровой релиз. Сообщения на русском по формату из спеки. У каждого тайтла всегда есть время следующей проверки, интервал зависит от состояния (скоро релиз — чаще, ничего не ожидается — реже). Изоляция ошибок из куска 0 сохраняется. Синхронная работа с базой не блокирует event loop. Спека: «События и дедупликация», «Расписание опроса», «Доставка» (формат).

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] Четыре события фильма обнаруживаются сравнением снимков и доставляются по одному разу; для переноса ключ дедупликации включает новую дату.
- [ ] Первый опрос после добавления фиксирует исходное состояние и не присылает старые даты как новость.
- [ ] Каждый тайтл после опроса получает время следующей проверки; сбойный источник откладывается, остальные опрашиваются.
- [ ] Все четыре типа доступны в «Тестовом событии».
- [ ] Тесты на точке ядра с поддельными часами и источником: каждое событие, перенос, отсутствие повтора, расписание.
- [ ] Пошаговая проверка в Telegram.
