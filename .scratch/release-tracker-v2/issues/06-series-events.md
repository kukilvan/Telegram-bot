# 06: События сериала

**Сложность:** сложный (движок событий, дедупликация)

**What to build:** по сериалам приходят события: объявлена дата нового сезона, сезон начался, вышла серия N (номер вышедшей серии и дата следующей), сезон закончился, дата следующей серии сдвинулась, сериал закрыт или отменён. Ключ дедупликации включает сезон и номер серии. Интервал опроса учитывает близость серии. Спека: «События и дедупликация», истории 43–48, 50.

**Blocked by:** 03, 05

**Status:** ready-for-agent

- [ ] Каждое событие обнаруживается и доставляется ровно один раз.
- [ ] Конец второго сезона с тем же числом серий, что и у первого, не отбрасывается как дубль.
- [ ] Перенос даты серии приходит с видом «до → после».
- [ ] Все типы есть в «Тестовом событии».
- [ ] Тесты на точке ядра для каждого события и случая дедупликации.
- [ ] Пошаговая проверка в Telegram.
