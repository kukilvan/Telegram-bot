# 09: Аниме-франшиза: сезоны по цепочке сиквелов

**Сложность:** сложный (сезоны аниме)

**What to build:** владелец добавляет аниме (поиск через Shikimori), и тайтлом становится франшиза целиком. Сезоны строятся по связям `related { relationKind }`: от любой записи по `prequel` к началу, затем по `sequel`. Сезоны — TV- и ONA-записи; запись с «Part N», «Cour N», «2nd Cour» присоединяется к предыдущему сезону как часть; фильмы — отдельная строка «фильмы франшизы»; OVA, спешлы, рекапы и ролики игнорируются. Карточка как у сериала, с русским названием из Shikimori. Спека: «Сезоны и части» (аниме), истории 11–13, 20.
