# 28: Меньше запросов и лишней работы

**Сложность:** обычный

**What to build:** четыре места, где бот делает лишнюю работу или тормозит сам себя.
1. Каждый опрос сериала скачивает все сезоны по одному запросу на сезон: у сериала из 30 сезонов это больше 45 секунд на проверку, и на это время встают опрос остальных тайтлов, поиск и добавление владельца.
2. Маскировка секретов перебирает переменные окружения на каждой строке журнала.
3. Ночной бэкап сам вычисляет путь к базе (не так, как его открывает бот) и выполняется прямо в цикле бота, так что на время копирования бот замирает.
4. Одно нажатие «Сезон N» четыре раза загружает тайтл со всеми сезонами.

Разбор: `review-2-problems.md`, Н3, Н7, Н8, Н10.

**Blocked by:** 25, 26 (`tracker_handlers.py` — по очереди)

**Status:** done (ждёт проверки владельцем)

## Сезоны сериала пачками (`providers/tmdb.py`, `sources/tmdb_series.py`)

- `TMDbProvider`: метод «сериал с сезонами» — `GET /tv/{id}?language=ru&append_to_response=season/1,…` (не больше 20 сезонов за запрос). 404 → `None`, 429 после повторов и другие коды — `TmdbHttpError`, как у `get_tv_show`.
- `TmdbSeriesSource.snapshot`: первый запрос — сериал (номера сезонов), затем по запросу на каждые 20 сезонов. Ответ разбирается в тот же `SeriesSnapshot`; сезон, которого нет в ответе, — пустой, как при 404 сейчас.
- Формат ответа с `append_to_response` проверить на настоящем ответе TMDb и сохранить образцы в `tests/fixtures/tmdb/` (сериал до 20 сезонов и сериал больше 20 сезонов). Значения ключей и токенов в образцы не попадают.
- Ядро, правила событий и снимки не меняются.

## Маскировка секретов (`utils/secrets_mask.py`, `config.py`)

- `remember_secrets()` собирает и сортирует значения секретных переменных один раз и запоминает. `mask_secrets` берёт запомненное; если ещё не запоминали — запоминает при первом вызове.
- `get_settings()` вызывает `remember_secrets()` сразу после `load_dotenv()`: журнал настраивается до чтения `.env`, и без этого токен из `.env` не попал бы в список.
- Тесты, меняющие окружение, после `setenv` вызывают `remember_secrets()`.

## Бэкап (`utils/backup.py`, `tracker/db.py`, `bot/main.py`)

- `app/tracker/db.py` даёт путь к файлу базы, разобранный из того же адреса, по которому база открывается. Бэкап берёт путь оттуда; папка бэкапов — `backups` рядом с файлом базы (как сейчас).
- Задача в 03:00 — асинхронная обёртка, копирование в `asyncio.to_thread`.

## Отметка сезона (`tracker/titles.py`, `core.py`, `bot/tracker_handlers.py`)

- `Tracker.toggle_season(title_id, number) -> list[WatchableSeason]`: в одной сессии проверяет тайтл (`UnknownTitle`) и сезон (`UnknownSeason`, в том числе сезон без вышедших серий), переворачивает отметку, пересчитывает статус, возвращает новый список сезонов с отметками.
- `flip_season`: вместо `title_card` + `watchable_seasons` + `set_season_watched` + `watchable_seasons` — один `toggle_season`, клавиатура из его ответа. Тексты ответов прежние. «Готово» — как сейчас.
- `set_season_watched` остаётся.

## Критерии

- [ ] Сериал из 25 сезонов: снимок собирается за 3 запроса (1 + 2 пачки), сезоны и серии совпадают с прежним способом на тех же данных (тест на образцах).
- [ ] Сбой пачки сезонов роняет весь снимок, как сбой одного сезона сейчас (тест).
- [ ] Строка журнала с токеном из окружения маскируется; окружение перебирается один раз на много строк (тест: подсчёт вызовов или подмена `os.environ` после запоминания).
- [ ] Токен, прочитанный из `.env` после настройки журнала, маскируется (тест).
- [ ] Бэкап копирует ту базу, которую открывает бот, и при другом адресе базы (тест с временной папкой); задача бэкапа не выполняется в цикле событий (тест).
- [ ] `toggle_season`: переворот туда и обратно, неизвестный тайтл, неизвестный и невышедший сезон, статус пересчитан (тесты на ядре); кнопка «Сезон N» в боте работает как раньше (существующие тесты зелёные).
- [ ] Набор тестов зелёный.
- [ ] Пошаговая проверка для владельца (команды PowerShell — по одной в блоке): остановить бота, запустить `.\start-bot.ps1`; в Telegram «➕ Добавить» → «Сериал» → `Симпсоны` → «Симпсоны (1989)» — карточка приходит за несколько секунд (до тикета — около минуты); в вопросе о сезонах нажать «Сезон 1» — появилась ✅, ещё раз — пропала; «Готово»; «🗑 Удалить» → «Да, удалить». Затем в PowerShell запустить бэкап вручную одной командой (агент даёт её в инструкции) и показать, что в `data\backups` появился свежий файл `tracker_db_<время>.db`. Остановить бота.
