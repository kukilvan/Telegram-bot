# 04: «Посмотрел» фильм → архив и продолжения франшизы

**Сложность:** обычный

**What to build:** под сообщением о фильме и в его карточке есть кнопка «Посмотрел»; фильм получает статус «Просмотрено» и уходит в архив. Раз в неделю архивный фильм проверяется по коллекции TMDb; при анонсе продолжения приходит событие «Анонсировано продолжение: …» с кнопкой «Следить», и новый тайтл добавляется только по нажатию. Спека: «Статусы, прогресс и архив» (истории 22, 28, 30), события фильма.

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] Статусы фильма «Хочу» и «Просмотрено»; «Посмотрел» работает из сообщения и из карточки.
- [ ] Архивный фильм проверяется раз в неделю только на продолжения, а не на собственный выход.
- [ ] «Следить» добавляет продолжение со статусом «Хочу»; без нажатия ничего не добавляется.
- [ ] Событие «анонсировано продолжение» есть в «Тестовом событии».
- [ ] Тесты на точке ядра; адаптер коллекции TMDb — на сохранённом ответе.
- [ ] Пошаговая проверка в Telegram.
