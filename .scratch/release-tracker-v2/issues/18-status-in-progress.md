# 18: Статус «В процессе» для начатых сериалов и аниме

**Сложность:** простой

**What to build:** сериал или аниме, у которого просмотрена часть вышедших сезонов и который ещё идёт, сейчас получает «Хочу», а по словарю «Хочу» — «ещё не начал». Добавляем статус «В процессе» и записываем правило статусов одной таблицей во всех документах. Закрытый и не начатый сериал по-прежнему «Хочу» с проверкой раз в неделю — это правильно, правятся только документы. Разбор: `review-fixes-problems.md`, П7, П8. Спека: `spec-review-fixes.md`, «Статусы».

**Blocked by:** 08

**Status:** done (ждёт проверки владельцем в Telegram)

## Правило

| Закрыт? | Отмечено из вышедшего | Статус | Слежение |
|---|---|---|---|
| нет | всё | Жду | да |
| нет | часть | **В процессе** | да |
| нет | ничего | Хочу | да |
| да | всё | Просмотрено | нет |
| да | часть | Досмотреть | нет |
| да | ничего | Хочу | да (раз в неделю) |

Без вышедших сезонов статус не меняется (как сейчас). У аниме «закрыт» пока не определяется — работают строки «нет».

## Код

- `models.py`: `STATUS_IN_PROGRESS = "in_progress"`.
- `progress.py`: строка «нет / часть» → «В процессе»; `AUTOMATIC_STATUSES` включает новый статус; описание модуля — та же таблица.
- `core.py`: `POLLED_STATUSES` включает «В процессе» (иначе начатые сериалы перестанут присылать серии).
- `cards.py`: подпись «В процессе».
- Миграции нет: тайтлы с «Хочу» опрашиваются и пересчитаются при ближайшем опросе или отметке сезона.

## Документы

- `CONTEXT.md`, «Досмотреть»: «закрыт, владелец начал (отмечен хотя бы один сезон), но просмотрел не всё».
- `spec.md`, история 26 и тикет 08: уточнение «закрыт и не начат — «Хочу», проверяется раз в неделю, чтобы не пропустить возвращение».
- `PROJECT_CONTEXT.md`: описание тикета 08 — таблица правила; строка «статус «В процессе» пока не ставится» убирается.

## Критерии

- [x] Каждая строка таблицы — тест на точке ядра.
- [x] «Жду» → у сериала вышел новый сезон → «В процессе».
- [x] «В процессе» опрашивается: новая серия такого сериала приходит событием.
- [x] Снятие отметок возвращает «Хочу»; отметка всех вышедших у идущего — «Жду».
- [x] Аниме с частью отмеченных сезонов — «В процессе».
- [x] Набор тестов зелёный.
- [ ] Пошаговая проверка в Telegram: добавить идущий сериал, отметить часть сезонов — в карточке «В процессе»; отметить все — «Жду».
