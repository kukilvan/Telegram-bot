# 07: Части сезона у сериалов

**Сложность:** сложный (сезоны)

**What to build:** если между соседними сериями одного сезона разрыв больше порога (по умолчанию 6 недель, настройка владельца), сезон делится на части. Карточка и события говорят «сезон 3, часть 1: вышло 8 из 8; часть 2 — с 27 марта», события начала и конца относятся к части. Спека: «Сезоны и части», история 14, «Настройки».

**Blocked by:** 06

**Status:** done

- [x] Порог хранится в настройках, по умолчанию 6 недель.
- [x] Части вычисляются из дат серий; без разрыва сезон остаётся одной частью и текст не упоминает части.
- [x] События «часть началась / закончилась» и дедупликация с номером части.
- [x] Тесты на точке ядра: сезон без разрыва, с одним разрывом, с разрывом ровно на пороге.
- [ ] Пошаговая проверка в Telegram (через «Тестовое событие»).
