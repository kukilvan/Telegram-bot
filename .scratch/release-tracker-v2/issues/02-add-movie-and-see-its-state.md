# 02: Добавить фильм и увидеть его состояние

**Сложность:** сложный (модель данных)

**What to build:** владелец в боте нажимает «Добавить» → «Фильм» → пишет название → выбирает результат TMDb кнопкой; тайтл появляется в новой базе со статусом «Хочу». Команда «Мои тайтлы» показывает список, у каждого фильма — текстовая карточка: русское и оригинальное название, год, жанры, даты премьеры в кино и цифрового релиза (или «не объявлена»). Повторное добавление того же фильма открывает его карточку, а не создаёт дубль. Это временный способ добавления до веб-приложения. Спека: «Модель данных» (тайтл, внешние идентификаторы, снимок состояния), история 6.

**Blocked by:** 01

**Status:** done
